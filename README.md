# Kassabok — releaser

Det här repot innehåller bara färdiga installerare för Kassabok, en
Windows-app för att hålla koll på utgifter.

Ingen källkod finns här. Den ligger i ett privat repo; det här repot är
publikt enbart för att appens uppdateringsfunktion ska kunna hämta
`latest.json` utan inloggning.

**Source code (zip)** som GitHub bifogar varje release innehåller alltså
bara den här filen. GitHub lägger till den automatiskt och den går inte att
ta bort.

Ladda ner `Kassabok_<version>_x64-setup.exe` under
[Releases](../../releases/latest) för att installera.
